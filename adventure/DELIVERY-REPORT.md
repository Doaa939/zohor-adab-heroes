# تقرير تسليم — طبقة تجربة المغامرة فوق «واحة التقنية» (الإصدار 3 — نهائي)

> طبقة عرض اختيارية فوق المنصة المعتمدة. هذا الإصدار يُبقي المحتوى التعليمي
> والبنية الوظيفية كما هي، ويرفع **جودة العوالم البصرية إلى مستوى لعبة تعليمية
> مصوّرة**. الصور الثماني المرفقة استُخدمت **مرجعًا فنيًا فقط**: لم تُدرَج داخل
> المشروع، ولم يُؤخَذ منها نص أو رقم أو اسم درس — كل النصوص تُولَّد من بيانات
> المنصة. كل نتيجة أدناه من تشغيل فعلي في Chromium (Playwright)، وكل مجموعة
> اختبار **تنتهي بـEXIT CODE = 0**.

---

## 1. الجديد في هذا الإصدار (بصري)
- استُبدل «مُصيّر البطاقات» بـ**مشاهد مصوّرة كثيفة**: لكل عالم خلفية طبقية عميقة
  (سماء/جبال أو أفق مدينة → مبانٍ وسطى → عناصر أمامية → مسار مضيء)، إضاءة أجواء،
  فوانيس/أضواء، ماء/طاقة متوهّجة، ومهمات هي **أماكن داخل المشهد** لا بطاقات.
- أُنشئت مجموعة عناصر مشهد مشتركة `adventure/scenery.js` (جبال، كثبان، نخيل،
  فوانيس، مبانٍ، جداول ماء/طاقة، نجوم، درونز، تدرّجات)، **يركّبها كل عالم بطريقته**
  — لا مُصيّر بصري واحد يُعاد تلوينه.
- اللوحات (Signage) صارت **صغيرة مدمجة في المشهد**، ملوّنة بالحالة (أخضر منجز /
  ذهبي حالي / خافت مقفل) مع أيقونة ✓/▶/قفل — لا بطاقات سوداء كبيرة.
- تمايز فوري: قرية دافئة (ذهبية) · رحلة قطار ليلية · متحف داخلي · وادٍ عند
  الغسق · قلعة حجرية · مدينة روبوتات نيونية · استوديو إنتاج · محطة فضائية للبيانات.

- **المهمة → الدرس الأصلي الصحيح مباشرةً**: جسر تنقّل مضمّن يستدعي واجهة كل منصة
  نفسها (`scene.go('lesson',{id})` / `s2lesson` / `WAHAT2.mountLesson(host,lesson)`
  / `G4S2.lesson.open`). لا يمسّ المحتوى أو المحرّك. **16/16 PASS**.
- **البوابة تعتمد نفس مِحوِّل التقدّم لكل عالم** (`adventure/progress.js`) — يفهم
  `progress[id].done|.mastered|.completed`، `progress.lessons[id].completed` (g1s1)،
  `lessons[id].mastered` (g2s1). «متابعة» تعرض العدد الصحيح: **8/8 PASS**.
