# واحَةُ التِّقْنِيَة — عالَمُ المُغامَرَةِ التَّعْليمِيُّ

تجربة تعليمية تفاعلية ثلاثية الأبعاد (بأسلوب لعبة مغامرات) لمادة **تقنية المعلومات — الصف الثاني — الفصل الدراسي الثاني**، مبنية فوق منهج «هَيَّا نُبَرْمِجُ» (١٤ درسًا · تطبيق ScratchJr كامل).

> إعداد وتنفيذ المحتوى التعليمي: **الأستاذة دعاء الجرواني** — وزارة التعليم، سلطنة عُمان.

## الفكرة

المحتوى التعليمي (الأهداف، الشرح، الأنشطة، الأسئلة، التدريبات، ترتيب الدروس، تطبيق ScratchJr) **محفوظ كما هو تمامًا** — لم يُحذف أو يُختصر أو يُعَد صياغته. أُضيفت فوقه **طبقة لعب واستكشاف (Gamification Layer)** تُغيّر طريقة الوصول إلى الدروس فقط:

- 🌍 **عالَمٌ افتتاحيّ سينمائيّ** بهوية عُمانية (سماء، واحة، حصن، نخيل، والهُدْهُد المرشد).
- 🗺️ **خريطة عالَم** فيها جزيرتان: جزيرة الفصل الأول (قريبًا) وجزيرة الفصل الثاني (مُفعّلة)، مع أركان الورشة والتقييم والمعلمة.
- 🏝️ **جزيرة بمسار مغامرة** تتوزّع فيه الدروس الأربعة عشر كـ **مراحل** ضمن أربع مناطق، تُضيء مرحلةً بعد مرحلة.
- ⭐ نجوم، مكافآت، فتح تدريجي للمراحل، شخصية مرشدة، انتقالات وتأثيرات — كلها تخدم المحتوى ولا تستبدله.

عند اختيار أي مرحلة يدخل الطالب إلى **الدرس الأصلي نفسه** دون أي تغيير.

## التشغيل

افتح `index.html` في المتصفّح. يعمل بالكامل دون إنترنت ومن أي مجلد أو ذاكرة USB — الخطوط والصور واللبنات والمنطق كلها مضمّنة داخل ملف واحد.

## البنية التقنية

طبقة اللعب مضافة كـ `<style>` و`<script>` اثنين فقط داخل `index.html`، وتعيد تصميم مشاهد التنقّل الثلاثة (`opening` · `hub` · `index`) فحسب، ثم تُحوّل إلى محرّك الدروس الأصلي عبر `ctx.go('lesson', { id })`. الملف الأصلي للمنهج مطابق حرفيًا (byte-for-byte) بعد إزالة هاتين الكتلتين.

> ملاحظة: تحتوي هذه الحزمة على الفصل الدراسي الثاني فقط؛ جزيرة الفصل الأول ستُفعَّل عند توفّر محتواه.
